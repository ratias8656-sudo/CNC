# 🛠️ צופה קודי CNC

תוכנה פשוטה להצגת קבצי התוכניות של המכונה (קודי G), עם הסבר בעברית לכל קוד.

**לא צריך להתקין שום דבר.** התוכנה היא קובץ אחד שנפתח בדפדפן.

## איך מתחילים? (3 צעדים)

1. **מורידים** את הקובץ `CNC-Viewer.html` למחשב.
   באתר GitHub: לוחצים על הכפתור הירוק **Code** ← **Download ZIP**, ופותחים את ה-ZIP.
2. **לוחצים פעמיים** על הקובץ `CNC-Viewer.html`. הוא ייפתח בדפדפן.
   (מומלץ להשתמש ב-**Google Chrome** או ב-**Microsoft Edge**.)
3. לוחצים על **📂 פתח תיקייה** ובוחרים את התיקייה שבה שמורים הקודים.

זהו! 🎉

> 💡 כדאי לשים קיצור דרך לקובץ על שולחן העבודה כדי לפתוח אותו מהר.

## מה אפשר לעשות?

| מה                         | איך                                                              |
|----------------------------|------------------------------------------------------------------|
| לראות תוכנית               | לוחצים על התוכנית ברשימה בצד ימין                               |
| לחפש תוכנית                | כותבים בתיבת החיפוש (מחפש בשם, בשם הקובץ ובתוך הקוד)            |
| לתת לתוכנית שם ברור        | לוחצים **✏️ שנה שם**. השם נשמר גם לפעם הבאה                      |
| להבין שורה                 | לוחצים על השורה, וההסבר בעברית מופיע בצד שמאל                   |
| למצוא קוד מסוים            | לוחצים על הקוד ברשימה "הקודים שמופיעים בתוכנית"                 |
| לראות אילו כלים יש בתוכנית | רשימת "כלים בתוכנית" בצד שמאל                                   |
| כתב גדול יותר              | כפתורי **א+ / א−** למעלה                                         |
| כרסומת או מחרטה            | בוחרים למעלה. ההסברים מתאימים את עצמם לסוג המכונה               |
| לפתוח שוב את אותה תיקייה   | כפתור **↩️** עם שם התיקייה האחרונה (בכרום / אדג')                |

## איך התוכנה מוצאת את השם של כל תוכנית?

1. אם נתתם לתוכנית שם בעצמכם, היא מציגה אותו.
2. אחרת היא לוקחת את ההערה הראשונה בקובץ. לדוגמה: `O1001 (TOP COVER - FINISH)` יוצג בשם **TOP COVER - FINISH**.
3. אם אין הערה, היא מציגה את שם הקובץ.

## אילו קבצים נקראים?

קבצים עם הסיומות `.nc .tap .gcode .ngc .cnc .txt .mpf .min .eia .iso` ועוד, וגם קבצים בלי סיומת (כמו `O1234`).
התוכנה קוראת גם תיקיות פנימיות, וגם קבצים ישנים שכתובה בהם עברית.

## דוגמאות

בתיקייה `דוגמאות` יש שתי תוכניות לדוגמה, אחת לכרסומת ואחת למחרטה. אפשר לפתוח אותה כדי לנסות את התוכנה.
